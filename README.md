SQL Data Warehouse Project

Building an end-to-end SQL data warehouse using SQL Server, Docker, and ETL processes, following the Medallion Architecture (Bronze, Silver, Gold).


About This Project

This project is part of my journey into data engineering. After spending time learning and practicing SQL, I wanted to challenge myself by working on something more practical that would help me understand how data engineering works beyond just writing queries.

I came across Data With Baraa's SQL Data Warehouse tutorial on YouTube, and it gave me a great starting point to put what I've been learning into practice.

The goal is to build a data warehouse from scratch using SQL Server, following the Medallion Architecture (Bronze, Silver, and Gold layers).

What I'm Learning

Through this project, I'm getting hands-on experience with:

SQL Server: Creating databases, schemas, tables, and stored procedures.

ETL Processes: Extracting, loading, cleaning, and transforming raw data.

Data Warehousing: Understanding how data moves through the Bronze, Silver, and Gold layers.

Docker & DBeaver: Setting up and working with a database environment on my Mac.

Data Modeling: Learning how to organize data for reporting and analysis.

A big thank you to Data With Baraa for making such a detailed, beginner-friendly project available for free.

His tutorial has helped me take an important step toward my goal of becoming a data engineer. It's giving me the opportunity to build on my SQL knowledge, learn new tools, and gain practical experience.

This project follows his tutorial, and I'm using it as a foundation to develop my own understanding and skills.
